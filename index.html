The memory system

The knowledge system I operate daily, where my agents and I answer from the same plain files. I benchmarked it against RAG, the default way to build AI memory, on 498 questions: plain files plus search answered 78 out of 100, RAG answered 55. The half of that result that went against my own design is published with it.

A national company spine

Colombia's mercantile registry, public contracting and open government data joined into one row per company, 1.75 million of them, then cut into a ranked analysis of which accounts are alive, have budget moving, and why each one is on the list. The written reason is the product.

An outbound machine, from zero

Isolated sending tenants, automated warmup, compliant multichannel sequences, and a CRM where stage, fit and priority are computed from activity dates so pipeline state cannot be hand-corrupted. Built at Frakkr, where I was co-founder and Head of Growth.

An offline call-QA pipeline

Local transcription feeds a rubric-scored teardown into a styled report in minutes instead of days. It runs on real sales calls, not synthetic data, and the recordings never touch a cloud API.

A public-tender watcher

A poller over Colombia's open contracting feed that reports what changed since its last run, so a market read starts from today's record instead of last month's.

HERRAMIENTAS · CON QUÉ TRABAJO

Con qué trabajo.

Las fuentes y las herramientas con las que se arma un análisis de mercado en Colombia.

Fuentes oficiales

SECOP · RUES · datos.gov.co. El registro mercantil y la contratación pública del Estado, cruzados por NIT en una sola base de trabajo.

Proceso

Python para depurar, cruzar y ordenar · Airtable para operar la lista de contacto del equipo comercial · n8n para mover información entre sistemas.

Escala

1.751.328 empresas colombianas, una fila por NIT, recortable por sector, ciudad, tamaño y señales de vigencia.

Reglas de contacto

Ley 2300 de 2023: horarios permitidos, frecuencia máxima y exclusión voluntaria, entregadas junto con cada análisis.

Stack: Claude Code with sub-agents, MCP servers and agent skills, context engineering, offline local models, Python and SQL data pipelines, Airtable, n8n, CRM and pipeline automation.

CLIENT WORK · ENTERPRISE

An enterprise retailer's real backlog.

A Colombian pharmacy retailer: enterprise scale, multi-site, high POS volume. I landed the engagement and ran it inside their engineering team, on their live Oracle and n8n workflows. Not a demo environment. How it went:

Embed and map

First deliverable: the architecture diagnostic that produced the systems map their own team did not have. You cannot automate what nobody can see.

Find the real work

The diagnostic surfaced a backlog of 14 recurring manual processes. That list became the roadmap, in their numbers. The agreed success metric: hours per process down to minutes.

Hand it back

A 1:1 training program on context engineering, agent skills and scheduled routines, so their own team runs the system. Documented, running, with the controls that say when it stops working.
